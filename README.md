# Robotics Computational Experiments

## Overview
This repository contains reproducible computational experiments focused on robotics, control theory, and physics-based simulation.

## Research Question
How does model uncertainty affect robot control performance?

## Planned Experiments
- Implement a simple robot dynamics model.
- Establish a baseline controller.
- Evaluate performance under model uncertainty and external disturbances.
- Compare control performance using quantitative metrics.

## Evaluation Metrics
- Tracking error
- Settling time
- Control effort
- Failure rate

## Tools
Python, NumPy, SciPy, Git

## Status
Project setup and experiment design in progress.

## Limitations
Simulation results depend on modeling assumptions and may not directly generalize to physical robots.
