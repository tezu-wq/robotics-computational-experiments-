# プロジェクト構成とロバスト性実験

この文書は、現在の回転系制御シミュレーションの構成と、PD・PID・LQRを慣性誤差・外乱条件で比較する方法を説明します。

## コードの役割

- `dynamics.py`：`RotationalSystem` が慣性と粘性減衰を持ち、角速度とトルクから角加速度 θ̈ = (τ - bω) / J を計算します。
- `controllers.py`：`PIDController` はPID型のトルク指令を返します。`ki=0` ならPDになります。`LQRController` は名目慣性・減衰と状態・入力の重みから連続時間LQRゲインを求めます。どちらも対称なトルク上限を設定できます。
- `simulation.py`：`simulate()` が各時刻で制御器を呼び、トルクを回転モデルへ渡して前進オイラー法で状態を更新します。角度・角速度・トルクの時系列を `SimulationResult` として返します。
- `metrics.py`：`evaluate()` はMAE、RMSE、最終誤差、整定時間、トルク二乗積分、ピークトルク、最終時点での成功判定を計算します。
- `experiments.py`：`run_experiment()` は従来の単一/設定済み試行用、`run_robustness_study()` は条件格子と反復比較用です。後者が生データ・統計表・図を出力します。
- `experiments/*.yaml`：物理パラメータ、条件範囲、制御器設定などをコードから分けて記述します。
- `scripts/run_robustness.py`：ロバスト性実験を起動するエントリーポイントです。
- `pyproject.toml`：Python依存関係を宣言します。LQRのリカッチ方程式にSciPyを使います。

## 実験条件と比較方法

`experiments/robustness.yaml` は、名目慣性1.0・減衰0.1のモデルを基準にします。真の慣性は名目値に慣性比を掛けて変化させ、減衰は名目値に固定します。目標は1 radのステップ、初期角度と角速度は0です。

各慣性比・外乱水準の組み合わせで30反復を行います。外乱水準を `L` とすると、反復ごとに一定トルクを一様分布 `[-L, +L]` から抽選します。同じ反復の同じ外乱値をPD・PID・LQRすべてに与えるペア比較です。乱数seedを固定しているため、設定を同じにすれば同じ外乱系列を再現できます。外乱水準0では全反復が同一条件になるため、標準偏差が0になるのが通常です。

制御器は以下の設定です。

- PD：`kp=8`, `ki=0`, `kd=3`
- PID：`kp=8`, `ki=1`, `kd=3`
- LQR：名目モデルで `q_angle=64`, `q_velocity=4`, `r_weight=1` を使用
- 全制御器で出力トルク上限は±20

これらのゲイン・重みは比較用に固定した設定です。自動最適化や厳密な同等性能調整はしていません。結果は指定した調整値に対する比較として解釈してください。

## 実行と生成物

依存関係をインストールした環境でリポジトリのルートから実行します。

```powershell
python scripts/run_robustness.py
```

`results/` に以下を作成します。

- `robustness_trials.csv`：各制御器・条件・反復の指標と、抽選された外乱トルク。seed、名目モデル、シミュレーション条件、制御器の種類とパラメータも記録します。
- `robustness_summary.csv`：制御器・慣性比・外乱水準ごとの平均と標本標準偏差。整定時間の統計は整定した反復だけから計算し、`settling_time_n` に有効数を記録します。成功率は0から1です。
- `robustness_curves.png`：慣性比に対するRMSE、MAE、整定時間、制御努力、成功率。色分けした線は外乱水準、帯は平均±標準偏差です。
- `robustness_tradeoff.png`：平均RMSEと平均制御努力の散布図。点の色は慣性比、点の大きさは外乱水準です。

## 評価指標の見方

RMSE・MAE・最終誤差は追従誤差、整定時間は許容誤差内に以後留まるまでの時間、制御努力は `integral(torque² dt)`、ピークトルクは最大絶対指令値です。成功はシミュレーション終了時の誤差が許容値以下かどうかで判定します。低誤差を得るために大きな入力を使うなど、指標間のトレードオフは散布図とCSVを見て考察します。

標準偏差は反復間のばらつきを表し、図の帯は±1標準偏差です。整定しなかった試行の整定時間はNaNなので、整定時間平均だけを見ると失敗が隠れる場合があります。必ず成功率と `settling_time_n` も合わせて確認します。

## 適用範囲と限界

この検証は1自由度の剛体回転モデルに限られます。慣性は一定値としてモデル化し、粘性減衰以外の摩擦、バックラッシュ、柔軟性、センサー雑音、観測誤差、通信遅延、アクチュエーターの動特性は含めません。アクチュエーターの制約はトルク指令の上下限だけです。外乱は時間変動する風や振動ではなく、各反復中に一定のランダムトルクです。目標角度も固定値へのステップです。

数値積分は前進オイラー法で、LQRのゲインは連続時間モデルから計算しています。実機性能を直接予測するものではなく、これらのモデル仮定の範囲で制御器の応答を比較するシミュレーションです。次の発展では、時間変動外乱、計測雑音、アクチュエーター応答、複数自由度モデルを順番に追加して仮定の影響を調べられます。
